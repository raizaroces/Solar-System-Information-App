# Solar System Information App

An educational Android application designed to display details about the planets in our solar system. Built as an academic exercise for our 2nd Year coursework using Java/Kotlin in Android Studio.

## Features

- **Interactive Dropdown Selection:** Uses an Android Spinner component to select and view different planets (Mercury, Venus, Earth, etc.).
- **Dynamic Content Rendering:** Automatically updates the displayed planet image and detailed astronomical overview based on user selection.
- **Scrollable Layout:** Incorporates smooth scrolling for long descriptions and structured text layouts.
- **Custom UI Design:** Uses a dark space-themed interface with custom card views and formatted text.
